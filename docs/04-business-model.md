## 1. Логика денег

Деньги делаются в порядке, который **снижает риск и не требует кремния сразу**:

```
Фаза 0–1 (2027):     Софт + облачный сервис на чужих чипах   → доход и клиенты
Фаза 2–3 (2028–29):  CRIMSON V1 → продажа железа и сервис    → масштаб
Фаза 4 (2030+):      Rack-scale, интерконнект, экосистема    → маржа монополиста
```

**Правило:** каждая фаза должна либо приносить деньги, либо доказанно снижать риск следующей. Дыры в кассе — через ADR.

## 3. Облачная экономика (главный экономический аргумент)

Подход: считаем $/токен честно, публикуем калькулятор.

```
$ / токен = (стоимость железа/срок службы + энергия + память + операции) / токенов за срок
```

Наши рычаги снижения $/токен:
1. **Narrow-оптимизация под инференс** (vs NVIDIA, обучение-ориентированный чип): 2–4× больше полезных токенов на ватт.
2. **INT4/FP4 + разреженность**: 2–4× плотность токенов на той же памяти.
3. **KV-cache-first**: длинный контекст без «хвоста» памяти — меньше переплата за память.
4. **Открытый рантайм**: без «программного налога» NVIDIA AI Enterprise.
5. **Свободный от роялти стек**: открытый ISA RISC-V + собственные векторные/матричные расширения (RVV) и AOT-путь ptx2ir (ADR-0006) — без патентных отчислений и без «наценки монополиста» (~80% в цене NVIDIA), которую закладывают в цену закрытые вендоры.
6. **Регионы без санкционных ограничений** — рынки, где NVIDIA не может продавать флагманы вообще.

**Публичная цель (с 2029):** в ежемесячном отчёте ROUGE-bench показывать $/токен на CRIMSON ≤ 50% от лучшей NVIDIA-конфигурации на той же модели.

## 5. Затраты и потребность в финансировании `[оценка]`

| Статья | Фаза | Сумма `[оценка]` |
|---|---|---|
| Команда софта (15–25 чел, 2 года) | 0–2 | $8–15M |
| Команда кремния (20–40 чел, 3 года) | 1–3 | $20–60M |
| Tapeout тестовый + V1 (маска, фабрика, упаковка) | 2–3 | $30–80M (зависит от узла) |
| HBM-контракты и вафли для пилотов | 3 | $20–50M |
| Облако (инфраструктура на чужих чипах) | 1–2 | $5–10M |
| Юристы (CUDA-compat, патенты, экспорт) | 0+ | $1–3M/год |

**Оценка «кислорода»:** чтобы дожить до дохода (2027) — **$6–10M**; до первого кремния (2029) — **~$80–150M** суммарно (софт уже зарабатывает к тому времени). Финансирование: seed → Series A/B → (возможно) долг/гранты ЕС на кремний.

**Rogue Strategy по финансированию:** приоритет — собственные доходы сервиса и open-source-комьюнити как «капитал развития», а не крупные VC-раунды на раннем этапе (меньше размытия и зависимости). Крупный внешний капитал допустим только под кремний (Фаза 2–3, tapeout и HBM), где без него не обойтись. Seed (roadmap 0.10) — минимально необходимый, чтобы дожить до первых доходов.

## 6. Go-To-Market (приоритеты)

1. **Open-source-комьюнити** (2026–27): вклад в vLLM, Triton, UXL, PyTorch. Мы — «команда, которая делает открытый AI-стек». Доверие → трафик → клиенты.
2. **Сегмент «эмбарго-стран» и «малых облаков»** (2027): облака, которые не могут купить NVIDIA, — первый крупный канал. Девиз: «работаем там, где вы работаете, без экспортных блоков [в легальных рамках]».
3. **Горизонтальный сегмент «дешёвый инференс»** (2028): стартапы агентов/приложений, которые живут на марже $/токен. Прямые продажи PLUS API self-service.
4. **Пилоты с провайдерами облаков** для CRIMSON (2029): 3 независимых пилота, публичные результаты.
