# ROUGE-V — план захвата рынка AI-вычислений

> **Кодовое имя проекта:** ROUGE-V ("красное V" — вектор атаки, направленный в сердце монополии).
> **Цель:** полный открытый стек AI-вычислений — собственное железо, программная платформа и облачный сервис — который отвоёвывает долю рынка у **NVIDIA, AMD и Intel** и за 3–4 года становится заметным независимым игроком, а к 2030–2031 — системообразующим.

Этот репозиторий — **боевой документ**, по которому команда движется. Все решения записываются сюда, обновляются итеративно и принимаются открыто.

---

## Что такое ROUGE-V

| Слой | Суть |
|---|---|
| **Железо** | Семейство AI-ускорителей (чиплетная архитектура, HBM, своя фабрика внутри-чипа и межстоечного соединения) |
| **Софт** | Открытый программный стек: компилятор, рантайм, библиотеки, CUDA-совместимость, нативный AI-стек |
| **Облако** | Сервис инференса/вычислений GPU-as-a-Service на собственном железе |
| **Стратегия** | Экономика инференса, открытые стандарты и экспортные ограничения как клинья в позиции монополистов |

## Ключевой тезис

> NVIDIA сильна не чипом, а **замкнутым циклом**: CUDA → библиотеки → экосистема → CoWoS/память. Атаковать чип — глупость. Атаковать **экономику единицы работы** и **закрытый стандарт** — стратегия.

## Как пользоваться

1. **Новичок читает**: `docs/00-vision.md` → `01-market-and-competition.md` → `05-roadmap.md`.
2. **Перед любым изменением архитектуры** добавляй запись в `decisions/` (формат — в `decisions/README.md`).
3. **Движение по плану** — дорожная карта в `docs/05-roadmap.md`; статусы фаз обновляются здесь же.
4. **Все ключевые цифры** (бюджеты, тайминги, характеристики) — честные оценки, помеченные как `[оценка]` или `[TBD]` с владельцем решения.

## Статус проекта

- **Фаза:** 0 — Фундамент (активна с Q4 2026)
- **Что сделано:** каркас стратегии, разведка рынка, черновые архитектуры, реестр решений (ADR-0001…0006, ADR-0004 — география/юрструктура предложен), прототип CUDA-совместимого слоя (`software/rouge-cuda` — 6/6 тестов) и прототип AOT-компилятора (`software/rouge-compiler` — 10/10 тестов: PTX → LLVM IR → нативный запуск без эмуляции, кросс-проверка `rv64gcv` на 3 ядрах). В обоих путях работают **shared memory + `bar.sync`**, **атомики `atom.add`/`red.add`** и **FP16/BF16** (один PTX-файл — два пути, бит-идентично); раскладка `.shared` экспортируется из ядра (`__rouge_*_query`), MLIR-контур стартовал (`rouge-simt-access-report`)
- **Ближайшие шаги:** см. [docs/05-roadmap.md](docs/05-roadmap.md), фаза 0, контрольные точки

## Принципы (полный список — в vision)

1. **Open-first.** Открытые стандарты (UXL/SYCL, Triton, UIF, UEC) — это наше оружие против CUDA, а не компромисс.
2. **Software-first.** Деньги и экосистема начинаются с софта, который работает и на чужих чипах; своё железо догоняет софт, а не наоборот.
3. **Экономика инференса.** Считаем в $/токен и TOPS/W, а не в пиковых флопсах (флопсы-гонка — ловушка NVIDIA).
4. **Открытые решения.** Каждое серьёзное решение — запись в ADR: проблема, варианты, выбор, цена.
