Формат: терминал на весь экран, без лица — только голос за кадром. 1080p,
шрифт терминала крупный (зритель читает с телефона). Все команды ниже
проверены 27.09.2026 — выводы дословные, тайминги реальные.

Правило сценария то же, что у статьи: ни одной цифры, которой нет в выводе
терминала. Не говорить: долю рынка, «налоги», сроки, железный роадмап
(`internal/` не светить ни кадром).

## 2:00 — полная версия (конкурс + YouTube)

### 0:00–0:12 — Крючок (чёрный экран, крупный текст)

На экране по строкам, с паузой:
```
CUDA-код.
Чужая видеокарта.
Без NVIDIA в цепочке.
```
Голос, спокойно: «CUDA-программа. Выполняется на видеокарте. Компилятор NVIDIA в этом не участвовал. Сейчас покажу.»

### 0:12–0:32 — Проблема (1 слайд, без мемов)

На экране схема:
```
.cu → nvcc → PTX (открытая спецификация)
PTX → ptx2ir → LLVM IR → clang → видеокарта
```
Голос: «Компилятор NVIDIA превращает код в PTX — текстовый ассемблер, спецификация открыта. Мы перехватываем эстафету здесь: переводим PTX в LLVM и собираем под ту видеокарту, которая есть. Один и тот же PTX — четыре цели: x86, RISC-V, AMD, NVIDIA.»

### 0:32–1:25 — Демо (терминал, живой прогон, монтаж не резать)

Кадр 1 — что за код (5 сек). Набираешь:
```sh
sed -n '1,12p' software/rouge-compiler/tests/kernels/gemm_tile.ptx
```
Зритель видит комментарий ядра. Голос: «Плиточный GEMM шестнадцать на шестнадцать. Обычный PTX.»

Кадр 2 — перевод под NVIDIA (8 сек). Набираешь:
```sh
./build/rouge-compiler/rouge-run software/rouge-compiler/tests/kernels/gemm_tile.ptx --target nvptx64-nvidia-cuda -o /tmp/demo.o
```
Вывод дословно:
```
translation: ok (11041 bytes of LLVM IR)
wrote /tmp/demo.o (backend accepted the IR)
OK
```
Голос: «Переводчик взял ядро и собрал объект для архитектуры sm_75. Бэкенд настоящий — из LLVM.»

Кадр 3 — исполнение на железе (25 сек, главный трюк). Набираешь:
```sh
nvidia-smi --query-gpu=name --format=csv,noheader
ctest --test-dir build -R "gpu_exec|nvcc_gpu_exec"
```
Вывод дословно:
```
NVIDIA GeForce MX450
1/3 Test #19: compiler_nvptx_gpu_exec ..........   Passed    5.06 sec
2/3 Test #20: compiler_nvptx_gpu_exec_atomic ...   Passed    0.21 sec
3/3 Test #21: compiler_nvcc_gpu_exec ...........   Passed    0.53 sec
100% tests passed out of 3
```
Голос, пока бегут секунды: «Карта — GeForce MX450. Первый тест: семь ядер, сверка побитово с эталоном. Второй: атомики. Третий: настоящее ядро, собранное самим nvcc, — сквозь наш переводчик на ту же карту. Всё сошлось.»
[По желанию, одна фраза о себе — только то, что готов светить публично.]

### 1:25–1:48 — Честная часть (текстовые карточки)

Железо нашло 2 бага, которых не видели 18 зелёных тестов:
