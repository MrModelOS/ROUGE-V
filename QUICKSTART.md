# ROUGE-V Quickstart — 30 секунд до первого запуска

## Предпосылки

- `clang` ≥ 17, `cmake` ≥ 3.20, `ninja`, `git`

```bash
clang --version && cmake --version && ninja --version
```

## Старт

```bash
git clone https://github.com/rouge-v/ROUGE-V.git
cd ROUGE-V

cmake -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build --output-on-failure
```

Ожидается: `100% tests passed` (10 тестов компилятора + 6 тестов CUDA-слоя, если собраны оба).

## Пример: PTX → LLVM IR (ptx2ir)

```bash
# собрать только компилятор если нужно
cmake -S software/rouge-compiler -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build

# прогнать тестовое ядро vadd через транслятор
./build/ptx2ir software/rouge-compiler/tests/kernels/vadd.ptx /tmp/vadd.ll
cat /tmp/vadd.ll
```

Вы увидите текстовый LLVM IR:

```llvm
; Generated by ROUGE-V ptx2ir — AOT path, do not edit
; PTX kernel: vadd
source_filename = "vadd.ptx"
target triple = "x86_64-pc-linux-gnu"
; ---- kernel metadata: .shared layout (rouge kernel info) ----
...
define void @vadd(i64 %arg0, i64 %arg1, i64 %arg2, i32 %arg3, ptr %launch) {
entry:
  ...
}

define i32 @__rouge_vadd_query(ptr %info) {
entry:
  ...
}
```

Скомпилировать IR в объектный файл и линковать с рантаймом:

```bash
clang -O2 -c /tmp/vadd.ll -o /tmp/vadd.o
# дальше — линковка с вашим хост-кодом + librouge-runtime.a
```

Другие ядра для пробы:

```bash
./build/ptx2ir software/rouge-compiler/tests/kernels/block_reduce.ptx /tmp/block_reduce.ll
./build/ptx2ir software/rouge-compiler/tests/kernels/atomic_reduce.ptx /tmp/atomic_reduce.ll
./build/ptx2ir software/rouge-compiler/tests/kernels/fp16_reduce.ptx /tmp/fp16_reduce.ll
```
